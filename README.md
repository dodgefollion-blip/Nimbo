# Nimbo

Nimbo — утилита для Windows x64.

## Возможности

- Отображение занятой физической памяти, лимита выделения памяти и системного файлового кэша.
- Кнопка **«Очистить RAM»** освобождает память процессов, уменьшая их рабочие наборы. Файлы при этом не удаляются, системный файловый кэш не меняется.
- Дополнительная очистка рабочего набора системного файлового кэша Windows.
- По желанию можно удалить подходящие файлы из %TEMP% текущего пользователя. Удаление выполняется без корзины и требует подтверждения. Занятые, недоступные и связанные элементы пропускаются; автоматически эта очистка не запускается.
- Автоматическая очистка по порогу и интервалу, локальная история и значок в системном трее.

Nimbo не изменяет список ожидания Windows. Система может повторно использовать или загрузить очищенные страницы, поэтому увеличение доступной памяти или ускорение работы не гарантируется. История не сохраняет имена процессов.

## Скачать и запустить

Скачайте Nimbo.exe из [последнего релиза](https://github.com/dodgefollion-blip/Nimbo/releases/latest) и запустите его. Это автономная сборка для Windows x64; отдельно устанавливать .NET не нужно.

## Сборка из исходников

Установите .NET 8 SDK и выполните команды:

~~~powershell
dotnet build .\Nimbo.csproj -c Release
dotnet publish .\Nimbo.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:SatelliteResourceLanguages=ru
~~~

## Локальные данные

Настройки и последние 200 записей очистки хранятся в %LOCALAPPDATA%\Nimbo.
